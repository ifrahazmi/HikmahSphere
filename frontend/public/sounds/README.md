# Notification Sounds for HikmahSphere

This directory contains notification sounds for prayer times and other alerts.

## Required Sound Files

To enable all notification sound options, add the following MP3 files to this directory:

1. **notification-default.mp3** - Default notification tone (simple beep/chime)
2. **adhan.mp3** - Traditional Adhan (call to prayer)
3. **notification-soft.mp3** - Soft, gentle notification tone
4. **birds-chirping.mp3** - Natural bird sounds
5. **mosque-bell.mp3** - Traditional mosque bell sound

## Sound Specifications

- **Format**: MP3
- **Recommended Duration**: 3-10 seconds
- **Recommended Bitrate**: 128 kbps
- **File Size**: Keep under 500KB for quick loading

## Notes

- If a sound file is not available, the app will fall back to the default notification sound
- The 'silent' option uses no audio file and shows only visual notifications
- Users can preview sounds in the Settings page before selecting
